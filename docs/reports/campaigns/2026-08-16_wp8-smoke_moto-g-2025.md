## Notes

- **No accessibility grant needed** — none of the four tests use the lock engine, so the
  Restricted-Settings a11y dance was skipped (adb reachability was all that was required). Phone set
  to stay awake while charging (`svc power stayon true`) for the run; reversible with `... false`.
- **DEX method-name fix (traceability).** The first attempt failed at *dex* time, not on the device:
  `dexBuilderProdDebugAndroidTest` rejected backtick test-method names containing **spaces**
  ("Space characters in SimpleName '…' are not allowed prior to DEX version 040" — DEX 040 needs
  minSdk 35; ours is 26). JVM unit tests keep space-names (never dexed); the four androidTest methods
  were renamed to camelCase. This would have failed the whole GMD matrix identically — surfaced here
  because a connected run assembles/dexes the test APK, which `compile*AndroidTestKotlin` alone does not.
- **Scope.** This is the real-hardware (arm64) leg of the WP8 matrix. The emulator legs remain: CI
  `ci` group (API 30+35) and the NucBox `full` group (26/29/30/33/35), per
  `docs/testing/WP8_GMD_MATRIX.md`. This report is one input to the M1 IS Phase-0 gate; it does not by
  itself close NFR-COMP-001 (which closes against the full executed matrix).
- Independent of the WP2 gating harness (OV-3/OV-4/F3), which stays the real-hardware *gating*
  evidence (WP5/WP6 device exits); this adds real-hardware *smoke* evidence for the WP8 suite.
