**Non-Functional Requirements (NFR)**

**1. Introduction**

**1.1 Purpose**

This document defines the measurable quality attributes governing the Android App Lock application. These requirements specify the operational, performance, security, reliability, maintainability, and usability characteristics that the implemented software shall satisfy throughout its lifecycle.

Unlike the Software Requirements Specification (SRS), which defines the application's functional behavior, this document establishes the quality objectives, constraints, measurable performance targets, and engineering standards applicable to all software components.

Compliance with these requirements shall be verified through testing, inspection, static analysis, benchmarking, security assessment, operational validation, or other approved verification methods.
