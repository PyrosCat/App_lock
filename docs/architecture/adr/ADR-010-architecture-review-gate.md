# ADR-010 — Require Architecture Review for Major Technology Changes

**Status:** Accepted (baseline) · **Date:** 2026-07-19 · **Source:** TAS §71/§75.2

## Context
Technology churn without review erodes architectural integrity and traceability.

## Decision
Changes to architectural structure, security boundaries, technology selections, or quality attributes require an ADR, architecture review, SRS/NFR impact evaluation, and documentation updates before implementation.

## Consequences
This ADR log is the mechanism; every future entry follows the template used here.
